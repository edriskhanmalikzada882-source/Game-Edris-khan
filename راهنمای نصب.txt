EDRIS WAR — عملیات قهرمان

راه‌اندازی:
1) فایل ZIP را استخراج کنید.
2) تمام محتویات پوشه EDRIS_WAR را در مخزن GitHub Pages خود آپلود کنید.
3) در تنظیمات مخزن: Settings → Pages → Deploy from a branch → main / root را انتخاب کنید.
4) پس از فعال شدن GitHub Pages، لینک سایت را در آیفون یا اندروید باز کنید.

کنترول:
- موبایل: دکمه‌های جهت‌نما برای حرکت و دکمه «شلیک» برای تیراندازی.
- کمپیوتر: کلیدهای جهت‌نما برای حرکت و Space برای شلیک.
- با لمس سمت مورد نظر روی صفحه، جهت هدف‌گیری تغییر می‌کند.

این نسخه نخست بازی دوبعدی مرورگری است و برای اجرا به نصب برنامه یا کتابخانه بیرونی نیاز ندارد.
